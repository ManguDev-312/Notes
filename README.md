# Notes

Notes is a powerful note-taking application designed with an extremely aesthetic, modern, and intuitive design. It offers unique and exceptional versatility, so much so that it can literally be run and operated even within plain text applications like Windows Notes or TextEdit on macOS.

Main Features
Quick note management and organization with a modern and clean user interface.

Carefully designed to make reading and writing enjoyable and effective.

Maximum versatility: lightweight and portable, it works anywhere, even within text editors like Windows Notes and macOS TextEdit.
